# ProPresenter-Custom-Bible

Custom Bible untuk **ProPresenter** dengan sumber data dari AYT dan FAYH.

---

## 📖 Sumber Data
- **AYT (Alkitab yang Terbuka)**  
  Data diambil dari [ayt.co](https://ayt.co/dev/datasets.php)

- **FAYH (Firman Allah yang Hidup)**  
  Data diperoleh melalui teknik scraping dari [alkitab.mobi/fayh](https://alkitab.mobi/fayh/)

- **IMB (Indonesian Modern Bible)**  
  Data diperoleh melalui teknik scraping dari [myimb.id](https://myimb.id/)

---

## 🔄 Proses Konversi
1. Data dikonversi ke format **.TXT**  per bible

2. Dari **TXT → USX → .rvbible**  
   Dokumentasi: [USX & .rvbible](https://github.com/martijnlentink/propresenter-custom-bibles)

---

## 📦 Output
- File akhir berupa **.rvbible** yang dapat diimport ke ProPresenter.
- Struktur mengikuti standar USX dan kompatibel dengan sistem custom Bible ProPresenter.

## 🚀 Cara Pakai
1. Unduh file **.rvbible** dari repo ini.  
2. Copy file ke folder berikut sesuai sistem operasi:

   - **Windows**  
     ```
     C:\ProgramData\RenewedVision\ProPresenter\Bibles\sideload
     ```

   - **macOS**  
     ```
     /Library/Application Support/RenewedVision/RVBibles/v2/
     ```

3. Buka ProPresenter → **Bibles 
4. Pilih versi Alkitab yang ingin digunakan.

## 📌 Catatan
- Repo ini hanya menyediakan Alkitab yang telah dikonversi untuk penggunaan di ProPresenter.
- Hak cipta teks Alkitab tetap milik penerbit masing-masing.
